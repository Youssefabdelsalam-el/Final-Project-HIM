# Educational Management System (Dashboard)

A web dashboard built to manage students, doctors, and academic courses. Currently focusing on the front-end layout and component structure.

## Tech Stack
* React.js
* Tailwind CSS
* React Icons

## What's Done So Far
* Modular React component architecture.
* Clean folder structure dividing Admin and Doctor portals and students 
* Responsive UI layouts (Tables, Cards, Schedules, and Navigation Drawers).

## Current Status & Roadmap
* **Current Phase:** Pure UI/UX design and responsive layout implementation only (No functional logic added yet).
* **Next Phase:** Integrating **Strapi CMS** to build the backend APIs and implementing full JavaScript/React application logic.
